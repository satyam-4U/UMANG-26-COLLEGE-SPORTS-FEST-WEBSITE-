# 🏆 UMANG – College Sports Fest Website

UMANG is the official college sports fest of **Government Engineering College, Vaishali**.  
This repository contains the complete frontend code for the UMANG Sports Fest website.

---

## 🚀 Features
- Responsive navigation bar
- Sports events section with clickable cards
- Auto-scroll & auto-fill registration system
- Rulebook guidance marquee
- Registration form
- Gallery section
- Contact & location with Google Maps
- Clean and professional UI

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
